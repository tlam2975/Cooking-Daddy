# Cooking Daddy

Its a Flutter project, for cooking. This currently released version v1.0.0 is the first prototype of the app.

## Getting Started

This app is for users (typically those who has few experiences in cooking) to learn a new skill. Apart from traditional recipe books which are plain texts, this one will be your friend. 

## Core Feature

The feature that sets this app from traditional recipe books is the companion. Of course it shows you the recipe. But when you actually starts to cook, Cooking Daddy is here to guide you through each steps. With the information it gathers, each step will show you specifically what to do, and what to look for (which most of the current apps does not provide). So even you did something wrong (like setting the wrong heat, using a bigger portion, etc), you still have room to wiggle. All data of the app is locally saved, so you don't have to log in, or rely on Internet connection.

## How to use

When open the app, you will see the main screen, which displays all recipes you have, along with categories in menu. From it, you can scroll, or search your desired. There is also a "Add recipe" button, which will then direct you to the screen where you can add a new recipe. The screen shows the fields for you to fill in, then categorise and save it. Choosing Edit recipe in home screen will also direct you to the this screen. With all the fields filled in, you can simply edit and save. With that design, it simplifies the use of this app.

And with user tapping in a recipe, it will then open the screen showing details of the recipe (like tools, steps, etc).From that, user can further choose "Start" button to start the most interesting part. Now, it will sequencially showing each step, including instruction, goal, notes and a timer that user have provided. This feature tells user exactly what each step is for, what a complete step is (to avoid underdone it). I belive this is really neccessary to newbie chefs, since they can really keep things on track.
