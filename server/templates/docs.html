API reference

Endpoints

All paths are relative to this deployment's base URL. POST routes accept JSON. Recipe generation requires a Gemini key configured on the server.

Every /api/ request requires a signed-in user's Firebase ID token in Authorization: Bearer <ID_TOKEN>. Missing or invalid tokens return 401; verification outages return 503. /health is public. Runtime logs use the separate operator password.
